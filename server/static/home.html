常见问题

你可能想问的

真的不抽水吗？钱去哪了？

平台服务费是 0%。矿机跑在你自己的机器上，矿池按你填的你自己的钱包地址结算， 钱直接进你的钱包，中间没有我们插手。你可能看到的第三方成本有两个：矿池手续费 0%~1%、 开源内核的开发者费 0%~2% —— 这两笔直接付给矿池和内核作者，不经过我们的账。 想省到最低：接 K1Pool（0% 池费）+ WildRig 0.51.x 接 PearlHash 官方池（0% 开发者费）。

需要什么样的机器？

Windows 10/11 64 位，带独立显卡的 PC。NVIDIA 30/40/50 系实测数据见上方算力表。 AMD 显卡可用 WildRig 内核，收益表现与 NVIDIA 有差异，建议先用群控台实测一轮再决定。

矿机要怎么加入我的账号？

矿机端内置了群控地址和令牌，首次登录时自动归属到对应账号，无需手工认领。 你在群控台登录后，就能看到名下所有矿机。多用户之间数据严格隔离，谁也看不到别人的机器。

游戏模式是干什么的？

网吧 / 家里有玩家要打游戏时开启，矿机检测到 GPU 被占用就自动暂停挖矿， 游戏结束后自动恢复。也可以在群控台远程开关，优先保证玩家体验。

换矿池 / 换内核要重装吗？

不用。群控台上下发指令，矿机端在 ≤30 秒的轮询周期内执行：缺失的内核会自动从群控下载、 写入配置、重启矿工，约 1 分钟恢复挖矿。也可以在矿机端本地下拉切换。

告警怎么触发？

矿机掉线、温度过高、算力异常下跌、显存不足都会进告警列表，在群控台和手机端都能看到， 处理完可以手动标记为已解决。

支持哪些矿池和内核？

内核支持 SRBMiner-MULTI、BzMiner、WildRig；矿池支持 PearlHash（官方专用，Anycast 全球就近）、 Kryptex、K1Pool 等。矿池节点列表会标注每个节点的真实落地机房， 避免出现「域名写 cn、实际落香港」这种情况。随时可以在矿机端切换。

算力表里的数字准吗？

那是我们自己 fleet 的实测值，不是厂商标称。同一型号不同机器会有差异， 温度、功耗墙设置、内核版本都会影响结果。日收益按实时币价折算，币价波动时数字同步变化。
